# بررسی فنی و کیفیت کد AVENOR

این گزارش مربوط به بازآرایی ۲۲ اکتبر است. بازطراحی Signal از ۲۹ اکتبر، لایهٔ نمایش قبلی را جایگزین کرده است: ۹ جزء CSS و ۱۶ الگوی بومی، با ساختار و تصاویر جدید. وضعیت فعلی در [مشخصات طراحی](design-specification.md) و [گزارش بررسی](verification.md) ثبت می‌شود؛ آمار و توضیحات بعدی این فایل سابقهٔ نسخهٔ قبل هستند.

تاریخ: ۲۲ اکتبر ۲۰۲۶. بررسی شامل سورس قالب، افزونه، ویرایشگر، الگوها، ابزار ساخت و راه‌اندازی، تست‌ها و صفحات عمومی است. پوشه‌های وابستگی و خروجی‌های موقت (`node_modules`، `vendor`، `.runtime` و گزارش‌های تست) سورس محصول محسوب نشده‌اند.

## اصلاحات انجام‌شده

| بخش | یافته و اصلاح |
| --- | --- |
| رندر PHP | کلاس چندمنظورهٔ `BlockRegistrar` از ۱۴٬۶۵۳ به ۱٬۳۳۶ بایت رسید؛ مسئولیت ثبت بلوک و رابط سازگار قبلی را نگه می‌دارد. کوئری، مجموعه، کارت، آیکون، پروفایل و فرم اجزای جدا هستند. |
| داده و نمایش | کوئری مجموعه‌ها در `CollectionQuery`، آماده‌سازی نمایش در `CollectionRenderer` و HTML در `views` قرار گرفت. خطای دریافت taxonomy مدیریت می‌شود؛ view دیگر فهرست خدمات را خودش از پایگاه داده نمی‌خواند. |
| فرم تماس | محدودیت طول فیلدها و پیام موفقیت منبع مشترک دارند. فرم HTML و اعتبارسنجی PHP از یک پیکربندی استفاده می‌کنند. شمارش و برش متن فارسی/Unicode با کاراکتر انجام می‌شود، نه بایت. محدودیت اندازهٔ درخواست HTTP همچنان بر حسب بایت باقی مانده است. |
| راه‌اندازی محتوا | `seed.php` از ۲۲٬۱۸۶ به ۶۰۴ بایت رسید و شش مرحلهٔ مشخص را فراخوانی می‌کند. بارگذاری الگو مشترک شد و اجرای دوباره، محتوای موجود را تغییر نداد. |
| ویرایشگر | ثبت بلوک، تنظیم مجموعه، فیلدهای کسب‌وکار و گزینه‌های مشترک تفکیک شدند. کنترل‌ها همچنان از اجزای بومی وردپرس استفاده می‌کنند. |
| موشن و منو | زمان‌بندی و لغو انیمیشن منبع مشترک دارند. تیتر، ورود عناصر، اسکرول، نشانگر و آیکون منو ماژول‌های مستقل‌اند. وابستگی‌ها و نسخهٔ هر فایل از import map بومی وردپرس مدیریت می‌شود. |
| CSS | ۶۸ اعلان بازنویسی‌شده با selector و شرایط یکسان حذف شد. ترتیب cascade حفظ شده است. سورس به ۱۸ بخش خوانا تقسیم و CSS نهایی سایت از هفت درخواست به یک درخواست تبدیل شد. |
| اندازهٔ استایل | CSS قالب قبلی در مجموع ۴۹٬۷۴۵ بایت بود؛ فایل فشردهٔ نهایی سایت ۳۸٬۳۶۹ بایت است. خروجی ویرایشگر جداست و موشن فرانت‌اند را اجرا نمی‌کند. |
| الگوها | ۲۳ الگوی بومی خواناتر شدند؛ یادداشت تصویر اصلی از الگوی مشترک استفاده می‌کند. تمام الگوها با parser واقعی گوتنبرگ معتبر بودند. |
| دسترس‌پذیری | پرش عنوان آرشیوها از H1 به H3 اصلاح شد: عنوان کارت در آرشیو H2 و زیر عنوان بخش در صفحهٔ اصلی H3 است. کلاس مشترک `card-title` ظاهر را مستقل از سطح عنوان نگه می‌دارد. |
| صفحه‌بندی | اندازهٔ صفحهٔ مجموعه در آرشیو از کوئری اصلی وردپرس گرفته می‌شود تا مسیر بومی `/page/N/` با تعداد آیتم‌های grid اختلاف نداشته باشد. تست مرزی چندصفحه‌ای اضافه شد. |
| کلیک هنگام موشن | حرکت ورود می‌توانست محدودهٔ لینک را زیر نشانگر جابه‌جا کند. اجزای تعاملی اکنون بدون جابه‌جایی محدودهٔ کلیک محو/ظاهر می‌شوند؛ زوم تصویر و حرکت عناصر غیرتعاملی باقی مانده است. |
| جلوگیری از بازگشت آشفتگی | بررسی خودکار ۱۱۹ فایل سورس، نمودار ۹ ماژول و ثبت ۱۸ جزء CSS اضافه شد. فایل بزرگ‌تر از ۱۰KB یا ۲۴۰ خط، ماژول بدون ثبت، وابستگی دوری و استایل جاافتاده باعث شکست بررسی می‌شود. |

بزرگ‌ترین فایل اجرایی سورس در قالب/افزونه اکنون حدود ۴٫۴KB است. محتوای اولیهٔ ابزار seed حداکثر حدود ۵٫۹KB در هر فایل دارد. فایل‌های build فشرده و lockfile وابستگی‌ها عمداً از این محدودیت سورس جدا هستند؛ ویرایش آن‌ها جای ویرایش اجزای اصلی نیست.

## مرزبندی قابل استفادهٔ مجدد

- `src/Blocks/CollectionQuery.php`: انتخاب محتوا، فیلتر، محتوای مرتبط و صفحه‌بندی.
- `src/Blocks/CollectionRenderer.php` و `CardRenderer.php`: نمایش یکسان در خانه، آرشیو و جزئیات.
- `src/Blocks/ContactForm.php` و `views/contact-form.php`: آماده‌سازی و نمایش فرم؛ اعتبارسنجی در `src/Contact/Validation.php`.
- `blocks/editor`: اجزای بومی تنظیمات مجموعه و metadata.
- `assets/js/shared`: مالکیت انیمیشن و تنظیمات مشترک دستگاه.
- `assets/js/motion` و `assets/js/navigation`: رفتارهای مستقل با رابط کوچک.
- `assets/css/manifest.json`: ترتیب صریح اجزای استایل؛ خروجی با `tools/build-styles.mjs` ساخته می‌شود.
- `tools/seed`: توابع مشترک و مراحل مستقل ساخت محتوا؛ migrationهای نسخه‌دار برای حفظ ویرایش‌های موجود نگه داشته شدند.

تکرار الزامیِ قراردادهای وردپرس، escaping در مرزهای خروجی و اعتبارسنجی مستقل سمت سرور حذف نشده است. یکسان‌کردن ظاهر یا حذف همهٔ شرط‌ها، به‌تنهایی نشانهٔ کد تمیز نیست؛ مرزبندی مسئولیت و قابل آزمون بودن مبنای این بازآرایی بوده است.

## بررسی‌های ظاهری و رفتاری

- ۸ صفحهٔ خانه، درباره، خدمات، راهکارها، تماس، جزئیات پروژه، مقالات و حریم خصوصی، در دو عرض ۱۴۴۰ و ۳۹۰ ثبت و مقایسه شدند. بعد از درنظرگرفتن تغییر عمدیِ سطح عنوان کارت، تفاوتی در چیدمان و استایل محاسبه‌شده ثبت نشد.
- بررسی خودکار axe روی همین ۸ صفحه و منوی موبایل، بعد از اصلاح عنوان‌ها هیچ violation در مجموعهٔ اجراشدهٔ WCAG A/AA و best-practice گزارش نکرد. این بررسی جای بررسی انسانی همهٔ نیازهای دسترس‌پذیری را نمی‌گیرد.
- اجرای دوبارهٔ seed، عنوان، متن، خلاصه و ترتیب رکوردهای موجود را حفظ کرد.
- تست‌های واقعی وردپرس، ویرایشگر، فرم با و بدون جاوااسکریپت، حریم خصوصی، دسترسی مدیریت، فیلترها، مسیرها، موشن و منوی موبایل در گزارش verification ثبت می‌شوند.

نتیجهٔ نهایی: **۲۲ تست مرورگر در ۴٫۴ دقیقه، ۱۴ تست PHP با ۸۰ assertion و بررسی syntax در ۷۵ فایل PHP پاس شدند**. build، lint جاوااسکریپت، WordPress-Core و بررسی مرزبندی اجزا نیز پاس شدند. داده‌های موقت فرم بعد از تست پاک شدند.

## وابستگی‌ها و موارد باقی‌مانده

ابزار رسمی ساخت وردپرس به **35.0.0** و cssnano به **8.0.10** ارتقا یافتند؛ نسخه‌ها در lockfile قفل هستند. شمار هشدارهای npm از **۱۱۰ به ۶۰** کاهش یافت. **۶۰ هشدار باقی‌مانده شامل ۲۴ high و ۳۶ moderate در ابزارها و وابستگی‌های توسعه است**؛ پاک یا پنهان نشده‌اند. پیشنهادهای audit برای downgrade اجباری ابزارهای فعلی اعمال نشدند.

ممیزی npm با حذف devDependencies، **صفر هشدار** و Composer نیز **صفر advisory** گزارش کرد. این نتیجه به معنی بررسی امنیتی کامل هستهٔ وردپرس یا تأیید نبود همهٔ آسیب‌پذیری‌ها نیست. گزارش خام ممیزی‌ها در `artifacts/audit` موجود است.

Docker روی این میزبان موجود نیست؛ اجرای MySQL و CI راه دور تأیید نشده‌اند. تست‌های محلی از وردپرس واقعی و SQLite استفاده کردند. ارسال ایمیل به صندوق خارجی و سنجش Core Web Vitals روی هاست نهایی نیز اجرا نشده است. اطلاعات تماس پیش‌فرض طبق درخواست مالک حفظ شده است.

«بدون هیچ تکرار یا خطای ممکن» ادعای قابل اثباتی نیست؛ تکرارها و مشکلات شناسایی‌شده اصلاح و کنترل‌های بازگشت برای ساختار فعلی اضافه شده‌اند.
